# Privacy Policy

**Effective Date:** March 28, 2026

## Octonomy Demo Extension

This extension allows users to demonstrate and test the Octonomy chat widget on websites of their choice.

### 1. Data Collection

The extension does not collect or transmit personally identifiable information.

### 2. Authentication

OAuth is used for secure sign-in. Tokens are stored locally in the browser and used only for communication with Octonomy services.

### 3. Website Access

Access to websites is required to inject and test the chat widget. This only occurs when the user explicitly interacts with the extension.

### 4. Cookies

Cookies may be used during authentication. The extension does not use cookies for tracking or advertising.

### 5. Local Storage

The extension stores session data and configuration locally in the browser. This data is not shared externally.

### 6. Remote Code

A chat widget script is loaded from a trusted Octonomy domain to provide core functionality. This occurs only when triggered by the user.

### 7. Data Usage

* No data selling
* No advertising usage
* No tracking of browsing history
* No third-party sharing

### 8. User Control

All actions are user-initiated.
